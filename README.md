## Краткое описание проекта

В ходе эксперимента была протестирована новая механика оплаты услуг на сайте. Контрольная группа пользовалась классической механикой оплаты покупки. Тестовая группа пользовалась новым функционалом. Были подобраны метрики для оценки эффективности нового функционала оплаты, проверены гипотезы о различия между группами и составлен итоговый вывод о целесообразности раскатывать новую механику оплаты на всех пользователей.
