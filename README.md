## Краткое описание проекта

В ходе эксперимента была протестирована новая механика оплаты услуг на сайте. Контрольная группа пользовалась классической механикой оплаты покупки. Тестовая группа пользовалась новым функционалом. Были подобраны метрики для оценки эффективности нового функционала оплаты, проверены гипотезы о различия между группами и составлен итоговый вывод о целесообразности выводить новую механику оплаты на всех пользователей.

## Цель проекта

Проанализировать эффективность нового функционала оплаты на сайте на основе данных пользователей в дни проведения эксперимента. В ходе анализа необходимо предобработать полученные выгрузки данных, подобрать релевантные метрики для оценки и проверить гипотезы о наличии/отсутствии статистически значимых различиях в выбранных метриках.

## Описание данных

#### groups.csv

Информация о принадлежности пользователей к контрольной или экспериментальной группе.

| Поле | Описание |
| --- | --- |
| `id` | Идентификатор пользователя |
| `grp` | Группа пользователя: `A` — контрольная, `B` — экспериментальная |


#### groups_add.csv

Дополнительный файл с пользователями, прислали спустя несколько дней после передачи данных

| Поле | Описание |
| --- | --- |
| `id` | Идентификатор пользователя |
| `grp` | Группа пользователя: `A` — контрольная, `B` — экспериментальная |


#### checks.csv

Информация об оплатах пользователей в дни проведения эксперимента.

| Поле | Описание |
| --- | --- |
| `student_id` | Идентификатор пользователя |
| `rev` | Сумма оплаты |


#### active_studs.csv

Информация о пользователях, которые зашли на платформу в дни проведения эксперимента (активные).

| Поле | Описание |
| --- | --- |
| `student_id` | Идентификатор пользователя |


## Результаты A/B-тестирования

1. Была проведена предобработка данных
1.1 Сдвоенные колонки с данными были разделены (`id` и `grp`)
1.2 Лишние/дублирующиеся колонки были удалены
1.3 Типы данных в колонках изменены на нужные
1.4 Пользователи проверены на уникальность `id`
1.5 Добавлены дополнительные данные, поступившие позже основного датасета на 2 дня
2. Объедение данных - оставлены только тех пользователи, которые заходили на платформу в дни проведения эксперимента (активные)
3. Добавление данных об оплатах пользователей на сайте в дни проведения эксперимента
3.1 Проверка количества пользователей, которые оплачивали покупки на сайте в дни проведения эксперимента (их **392**)
3.2 Проверка качества данных, заполнение пропусков в данных
4. Подбор метрик: Конверсия в оплату (conversion rate) и ARPPU (cредняя выручка с платящего пользователя)
5. Обоснование выбора метрик и метода проверки гипотез 1 и 2
6. Проверка гипотез с помощью статистических тестов: хи-квадрат; параметрический t-test (t-критерий Стьюдента); непараметрический тест Манна-Уитни
7. Общий вывод по проведенному эксперименту
